# OpenMusic Website

This is the official website for OpenMusic, built with Vue.js and Vite.

## Development

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

## Build for Production

Build the website:
```bash
npm run build
```

The built files will be in the `dist` folder, ready for deployment.

## Preview Production Build

```bash
npm run preview
```

## Deployment

The `dist` folder can be deployed to any static hosting service:
- Netlify
- Vercel
- GitHub Pages
- Firebase Hosting
- AWS S3 + CloudFront
- Any web server (nginx, Apache, etc.)
